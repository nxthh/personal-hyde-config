# Custom HyDE Configuration

This repository contains a personalized setup based on **HyDE** (Hyprland Development Environment).

> **Disclaimer:** This repository is an individual setup maintained for personal use. All original concepts, core scripts, architecture, and default configurations belong to the original authors and upstream project maintainers.

---

## 📜 Credits & Acknowledgments

This configuration would not be possible without the incredible work of the open-source community, particularly the core developers and maintainers of HyDE and Hyprland.

### 🌟 Upstream Project & Primary Authors
* **[HyDE Project](https://github.com/HyDE-Project/HyDE)** – The base development environment and framework for Hyprland on Arch Linux.
* **[prasanthrangan](https://github.com/prasanthrangan)** – Original creator of `hyprdots` and key pioneer of the HyDE ecosystem.
* **HyDE Community & Maintainers** – For their continuous development, CLI tooling, theme management, and ecosystem support.

### 🖥️ Compositor & Core Utilities
* **[Hyprland](https://github.com/hyprwm/Hyprland)** ([Vaxry](https://github.com/vaxerski)) – Independent, dynamic tiling Wayland compositor.
* **[Waybar](https://github.com/Alexays/Waybar)** – Highly customizable status bar for Wayland compositors.
* **[Rofi-Wayland](https://github.com/lbonn/rofi-file-browser-extension)** – Window switcher, application launcher, and dmenu replacement.
* **[SWWW](https://github.com/LGFML/swww)** – Efficient wallpaper daemon for Wayland.
* **[Dunst](https://github.com/dunst-project/dunst)** / **[SwayNC](https://github.com/ErikReider/SwayNotificationCenter)** – Desktop notification daemons.
* **[HyDE CLI](https://github.com/HyDE-Project/HyDE-cli)** – Command-line utility for managing HyDE configurations and components.

### 🎨 Themes & Color Generation
* **Wallbash Engine** – Dynamic color palette extraction based on desktop wallpaper.
* **Theme Maintainers** – Color schemes and aesthetics inspired by community themes including Catppuccin, Tokyo Night, Rosé Pine, Gruvbox, and Decay.
